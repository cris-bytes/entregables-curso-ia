# N02 · Renovación y reservas

Caso ficticio BiblioLab · versión 1.0 · Grupo X-Ray

## N02-S1 · Renovación

Se permite una sola renovación por el mismo plazo original cuando el libro no está vencido y no tiene reservas de otras personas. La renovación se solicita antes de la fecha de devolución. Una segunda renovación no está permitida. El asistente no realiza renovaciones; solamente explica la regla.

## N02-S2 · Recogida de reservas

Una reserva de libro se conserva durante 2 días hábiles desde el aviso de disponibilidad. El día del aviso no se cuenta. Después se libera al siguiente solicitante. No se cobra por reservar. El catálogo es una instantánea de prueba y no contiene reservas personales.
